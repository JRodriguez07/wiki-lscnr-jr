# Pizza Delivery

Clock in at Pizza This, rent a scooter, and run pies around the city. Clean cash, no wanted level — as long as you stay on the scooter and hit the door.

Cops and other government jobs can't do this one.

## How to start

1. Find the **Pizza Delivery Job** blip in Vinewood (Pizza This).
2. Press **E** to rent a delivery scooter. That's a **$3,000** deposit from your **bank**. You get it back when you return the scooter to the shop.
3. Get on the scooter and press **G** to start a run.
4. Grab the order at the counter, then follow the GPS to the house.

Bring the scooter back to the same spot and press **E** to return it. Leave it somewhere else and you lose the deposit.

## The run

You'll get one to five pies in a batch. Pick them up at the shop, then deliver each one on foot at the door — hop off the scooter, press **E**.

Stay close to the scooter. If you're off it too long (about a minute), the run fails.

There's a timer on each drop. Make it before the clock hits zero and you keep the **tip** and your **streak**. Show up late and you still get paid for the distance, but the tip and streak are gone.

<Callout type="info">
Need to cancel? Finish or drop the current run before you can return the scooter.
</Callout>

## Pay

Payout is **cash**, from the pizza shop.

- **Distance.** Farther houses pay more. A short Vinewood hop is a couple thousand; a long ride across town is several thousand more.
- **Tip.** On-time drops add a small extra (a couple hundred dollars).
- **Streak.** Each on-time drop in a row adds more. Fail a timer and the streak resets.
- **Batch.** If the shop hands you several pizzas at once, those deliveries pay **20% extra**.

### Rough pay

Ballpark per house, not including a huge streak:

| | |
| --- | --- |
| Nearby drop | About **$1,500–$4,000** plus a small tip if you're on time |
| Cross-town drop | About **$5,000–$15,000** plus tip |
| Streak | Extra **hundreds** per consecutive on-time drop |
| Multi-pizza batch | **+20%** on those deliveries |

The deposit is separate. Return the scooter and the $3,000 goes back to your bank.

## Tips

- **G starts the job, E is for the shop and the door.** Don't mash E on the scooter looking for a new run.
- Keep the rented scooter. A random bike from the street won't count.
- Don't wander off on foot. The fail timer is short.
- Stack streaks on purpose: stay on time, then grab another batch while you're hot.
- Government duty blocks the job. Clock out first if you're a cop.
